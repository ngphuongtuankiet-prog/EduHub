## Domain Classes

The EduHub project uses domain classes to represent students, courses, enrollments, instructors, and departments.

- `Student`: stores student information.
- `Course`: stores course information.
- `Enrollment`: represents a student's course registration.
- `Instructor`: stores instructor information.
- `Department`: stores department information.

The classes validate input data through factory methods and use private setters to protect their properties.# EduHub
